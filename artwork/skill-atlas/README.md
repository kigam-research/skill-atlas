# 여백 장식 이미지 (skill-atlas)

- 출처: 사용자가 전달한 패키지 `skill-atlas-web-images` (2026-09-21, v1.0). 직접 작성한 SVG 벡터 일러스트의 WebP 파생본이며 생성형 이미지 모델 출력물이 아니다(패키지 manifest 기재). 원본 SVG·PNG는 패키지에 보존하고 저장소에는 WebP 25종만 둔다.
- 내용: 5개 화면(explore·modules·rankings·review·history) × 상단(2560×640 또는 2560×400)·좌(480×1600)·우(480×1600)·하단(2560×240) + 모바일 상단(1080×800). 상단·모바일은 네이비 배경 포함, 좌·우·하단은 투명. 텍스트·로고·버튼 없음.
- 의미: 설명용 장식이다. 실제 지질도·지층·MPM 예측지도·측정된 스킬 성능이 아니다. 과학 결과 그림을 대체하지 않는다.
- 적용: `web/src/artwork.css`가 `.app-shell[data-page]`별 변수로 배너·footer·1536px 이상 좌우 여백에만 CSS 배경으로 붙인다. 검토실(review)은 정의하지 않아 표시되지 않으며, 결과 패널이 열리면 모두 끈다. `manifest.json`에 각 WebP의 SHA-256과 원본 SVG SHA-256을 기록했다.
