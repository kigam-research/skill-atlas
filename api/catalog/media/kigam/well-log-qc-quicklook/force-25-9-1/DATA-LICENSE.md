# Data licence

FORCE 2020 well log and lithofacies dataset (Bormann P., Aursand P., Dilib F., Dischington P., Manral S. 2020),
Zenodo record 10.5281/zenodo.4351156, licence **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/; Zenodo API
`metadata.license.id = cc-by-4.0`, checked 2026-10-10). The record states: "The original well log data comes from the
Norwegian government and is provided by a NOLD 2.0 license" (Norwegian Licence for Open Government Data 2.0,
https://data.norge.no/nlod/en/2.0). The logs were "slightly cleaned up and partially despiked" by the organisers;
lithofacies labels are hand interpretations (Explocrowd).

Cite: Bormann et al. 2020, FORCE Machine Learning Competition, https://github.com/bolgebrygg/Force-2020-Machine-Learning-competition
and doi:10.5281/zenodo.4351156. Bytes in this asset were taken from the GitHub repository (same files as the Zenodo record's
competition data; the repository itself declares no licence file).
